# 키보드와 화면 배치

시험장은 윈도우 PC의 크롬 안에서 도는 웹 IDE다. 에디터는 VS Code 계열, 터미널은 리눅스 bash.
메뉴 이름과 단축키가 조금 다를 수 있다. 처음 써 볼 때 하나씩 눌러 보고 안 되면 메뉴(탭 우클릭, 오른쪽 위 버튼)로 같은 일을 한다.

## 1. md를 보던 위치 그대로 두는 배치

원인: 한 창에서 탭을 바꾸면 미리보기가 다시 그려지면서 맨 위로 돌아간다.
해결: 창을 둘로 나눠 오른쪽 창은 steps 파일 전용으로 두고, 그 창에서는 탭을 바꾸지 않는다.

1. steps 파일을 연 상태에서 에디터 오른쪽 위 "창 나누기" 버튼 (VS Code 단축키 `Ctrl+\`)
2. 오른쪽 창에서 그 파일의 미리보기를 연다: 오른쪽 위 Markdown(미리보기) 버튼 또는 `Ctrl+Shift+V`
3. 오른쪽 창 탭 우클릭 → 고정(Pin)
4. 작업 파일은 왼쪽 창에서만 연다. 파일 열기는 `Ctrl+P` 후 이름 일부
5. 그래도 위치가 튀면 미리보기 대신 원문(md 그대로)으로 본다. 원문은 스크롤 위치가 잘 유지된다
6. md 두 개를 같이 볼 때: 오른쪽 창 탭 우클릭 → 아래로 나누기(Split Down)

steps 파일이 한 화면 분량이라 위치를 잃어도 다시 찾기 쉽다.

## 2. 터미널 (bash)

| 하고 싶은 것 | 키 |
| --- | --- |
| 줄 맨 앞 / 맨 끝 | `Home` / `End` (또는 `Ctrl+A` / `Ctrl+E`) |
| 단어 단위 이동 | `Ctrl+←` / `Ctrl+→` (안 되면 `Alt+B` / `Alt+F`) |
| 커서 앞 전부 지우기 / 뒤 전부 지우기 | `Ctrl+U` / `Ctrl+K` |
| 앞 단어 지우기 | `Alt+Backspace` (`Ctrl+W`는 브라우저 탭이 닫히니 쓰지 않는다) |
| 이전 명령 / 명령 검색 | `↑` / `Ctrl+R` 후 글자 |
| 화면 지우기 | `Ctrl+L` |
| 붙여넣기 / 복사 | `Ctrl+Shift+V` / 글자 선택 후 `Ctrl+Shift+C` |
| 실행 중인 명령 끄기 | 선택 없이 `Ctrl+C` (서버 끌 때만) |

명령어를 치기 전에 한/영 상태 확인.

## 3. Codex 입력창

- 근본 해법: 긴 프롬프트는 터미널에서 치지 않는다. notes/prompt.md에 쓰고(에디터라 마우스로 고칠 수 있다) Codex에는 `notes/prompt.md 읽고 그대로 진행해`
- 줄 맨 앞·끝: `Home` / `End`
- 작업 멈추기: `Esc` (처음 한 번 눌러 보고 전체화면이 풀리지 않는지 확인)
- 승인 대기로 멈춰 있으면 화면의 명령을 읽고 승인 또는 거절
- 업데이트 권유가 떠도 업데이트하지 않는다 (금지)

## 4. 에디터

| 하고 싶은 것 | 키 |
| --- | --- |
| 파일 이름으로 열기 | `Ctrl+P` |
| 전체 검색 | `Ctrl+Shift+F` |
| 탐색기 접기·펴기 | `Ctrl+B` |
| 터미널 패널 보이기·숨기기 | ``Ctrl+` `` |
| 저장 | `Ctrl+S` (Codex가 고친 파일과 충돌하면 "외부 변경 불러오기") |

내가 만든 웹을 미리보기에서 로그인해 볼 때 브라우저의 비밀번호 저장 창이 뜨면 전체화면 경고가 날 수 있다. 시작 전에 Chrome 설정에서 비밀번호 저장 제안을 꺼 둔다.

누르지 않기: `Ctrl+W`(탭 닫힘), `Alt+Tab`, `Win` 키, `PrtSc`, `Win+Shift+S`(화면 이탈·캡처로 감지될 수 있음)
