## 함정 점검 (해당하면 근거와 함께)

- 반복 기재 값: 상세 행마다 상위 묶음의 값이 반복되나 (예: 주문 상세 행마다 같은 주문 총액 → 묶어서 한 번만 센다)
- 날짜 기준: 업무 기준일과 실제 발생 시각이 다른가, 시간대(UTC/KST)와 날짜 경계는 어떤가
- 방향과 순서: 같은 두 대상이라도 방향이나 순서에 따라 값이 다른가 (예: 보낸 쪽/받은 쪽, 전/후 상태)
- 기록과 전체: 로그·이력에 남은 것을 전체 대상으로 보고 있지 않나 (기록 없음 ≠ 0, 기록 = 일어난 일의 일부일 수 있음)
- 같은 정보, 다른 파일: 두 파일에 같은 정보가 있을 때 값이 다르면 어느 쪽이 기준인가
- 문서와 실제: 설명 문서와 실제 값이 다른 곳
- 빈 값과 형식: 빈 값의 뜻, 형식이 섞인 열
- 크기: 통째로 읽으면 안 되는 큰 파일
